# 🪲 Beetles AI

**Verify before you publish. Know why, not just what.**

The forensic image verification tool built for journalists,
not developers.

## Why Beetles AI?

Existing AI image detectors give developers a score.
Beetles AI gives journalists a **verdict**.

### Features

- 🤖 **Multi-Model Consensus** - 3 AI models vote on every image
- 🔍 **Metadata Forensics** - EXIF analysis catches what AI models miss
- 🧠 **Explainable Results** - Know WHY, not just WHAT
- 📰 **Shareability Verdict** - Clear actions like "DO NOT PUBLISH"
- ⚡ **Fast Analysis** - Results in seconds

## Live Demo

🌐 **Try it now:** [beetles-ai.streamlit.app](https://beetles-ai.streamlit.app)

## Tech Stack

- **Python** + **Streamlit** for the web app
- **Hugging Face Transformers** for AI models
- **PIL** for image processing
- **ExifRead** for metadata forensics
